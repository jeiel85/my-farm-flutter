마이팜 개인정보처리방침

시행일 2026년 10월 6일 · 앱: 마이팜(My Farm, com.jeiel85.myfarm)

요약

  • 마이팜은 계정·로그인이 없고, 개발자 서버로 아무 정보도 보내지 않습니다.
  • 모든 농장 기록(작물·가축·물·수확·재고·장부·일정)은 기기 안에 저장됩니다. Android 시스템 백업이 켜져 있으면 사용자의 Google 계정 백업에도 들어갈 수 있습니다(개발자는 볼 수 없음).
  • 광고·분석·추적 SDK를 쓰지 않습니다.

1. 기기 안에 저장하는 정보

사용자가 입력한 농장 정보와 기록은 기기(웹 데모는 브라우저)의 앱 저장소에만 저장됩니다. 사용자가 직접 백업 파일(JSON)이나 장부 CSV를 내보낼 때만 사용자가 고른 위치에 파일이 만들어집니다. 앱을 삭제하면 기기 안의 기록도 함께 지워집니다.

Android 시스템 백업: 기기 설정에서 Google 백업을 켜 두었다면 Android가 앱 데이터를 사용자의 Google 계정에 백업하고, 새 기기로 옮기거나 다시 설치할 때 복원할 수 있습니다. 이 백업은 Google이 사용자 계정에 보관하며 개발자는 접근할 수 없습니다. 원하지 않으면 기기 설정 → Google → 백업에서 끌 수 있고, 앱 안의 프로필 → 예시 농장으로 초기화로 기록을 지울 수 있습니다.

2. 외부로 보내는 정보

  • 날씨 조회(Open-Meteo): 프로필에 입력한 농장 위치의 위도·경도를 Open-Meteo에 보내 날씨를 받습니다. 기기의 위치 권한은 쓰지 않으며, 다른 식별 정보는 함께 보내지 않습니다. Open-Meteo는 요청한 IP 주소를 볼 수 있습니다.
  • 앱 업데이트 확인(선택, Android): 사용자가 켰을 때만 GitHub 릴리스에서 업데이트 정보 파일을 받습니다. 요청에 식별자를 붙이지 않으며, GitHub는 요청한 IP 주소를 볼 수 있습니다.

3. 권한

  • 인터넷: 날씨 조회와 (켰을 때) 업데이트 확인.
  • 알림(Android 13 이상, 사용자가 알림을 켰을 때): 물주기·급이·백신 일정 알림. 알림은 기기 안에서만 예약합니다.
  • 진동: 알림을 보낼 때 기기 설정에 따라 진동합니다.
  • 부팅 완료 수신: 재부팅 뒤 예약한 알림을 다시 겁니다.
  • 앱 설치 요청(Android): 사용자가 업데이트를 고르면 내려받은 APK를 시스템 설치 화면으로 넘깁니다.

4. 제3자 제공·판매

개발자는 사용자 정보를 수집하지 않으므로 제3자에게 제공하거나 판매하지 않습니다.

5. 아동

마이팜은 아동을 대상으로 하지 않으며, 아동의 개인정보를 수집하지 않습니다.

6. 문의

My Farm Privacy Policy

Effective October 6, 2026 · App: My Farm (com.jeiel85.myfarm)

  • My Farm has no accounts and sends nothing to the developer's servers. All farm records are stored on your device (or your browser for the web demo). If Android system backup is on, Android may include the app data in your Google account backup and restore it on a new device or reinstall; the developer cannot access it, and you can turn it off in device settings. No ads, analytics or tracking SDKs.
  • Weather: the latitude and longitude you enter for your farm are sent to Open-Meteo to fetch the forecast. The device location permission is not used.
  • Update check (optional, Android): when you turn it on, the app downloads an update manifest from GitHub Releases without any identifier. GitHub and Open-Meteo can see the requesting IP address.
  • Permissions: internet; notifications (Android 13+, only if you enable reminders; scheduled on the device); vibrate (for reminders, per device settings); boot completed (to restore scheduled reminders); request install packages (to hand a downloaded update to the system installer).
  • The developer does not collect, share or sell personal data. The app is not directed at children.
  • Contact: GitHub issues.
